# Haarlem Night Sky

A free stargazing and astrophotography forecast for Haarlem, the Netherlands: a score for each night, plus cloud,
seeing, transparency, darkness, moon, planets, meteor showers and aurora.

**Live:** https://samjongman.github.io/haarlem-night-sky/

It is one static page. Each visitor's browser fetches the forecast directly from
[Open-Meteo](https://open-meteo.com/) (CC BY 4.0), the ECMWF ensemble and Copernicus CAMS through Open-Meteo, and the
Kp forecast from [NOAA SWPC](https://www.swpc.noaa.gov/). Sun, moon and planet positions are calculated in the browser
with [Astronomy Engine](https://github.com/cosinekitty/astronomy).
